# Sicherheitshinweise melden

Bitte melden Sie vermutete Schwachstellen in CT M365 Connect **nicht** über öffentliche GitHub-Issues, sondern direkt an
den Support der Computer Trend IT-Solution GmbH (support@computer-trend.ch). Wir melden uns so rasch wie möglich und
stimmen das weitere Vorgehen mit Ihnen ab.

Hilfreich sind:

- betroffene Version (System → Systemstatus),
- Beschreibung und Schritte zum Nachvollziehen,
- mögliche Auswirkungen.

Unterstützt wird jeweils die neueste veröffentlichte Version. Updates stehen unter
[Releases](https://github.com/c-trend/M365Connect-Public/releases) bereit und lassen sich direkt in der Oberfläche
installieren.
